# Avisos de terceros

Vortex CRM incluye o usa los siguientes componentes de terceros, cada uno con su propia licencia.

| Componente | Uso | Licencia |
|---|---|---|
| [Montserrat](https://github.com/JulietaUla/Montserrat) | Tipografía de la interfaz (`src/VortexCrm/wwwroot/fonts`) | SIL Open Font License 1.1 ([texto](../src/VortexCrm/wwwroot/fonts/OFL.txt)) |
| [Open Sans](https://github.com/googlefonts/opensans) | Tipografía de los PDF (`src/VortexCrm.Core/Recursos/Fuentes`) | SIL Open Font License 1.1 ([texto](../src/VortexCrm.Core/Recursos/Fuentes/OFL.txt)) |
| [PDFsharp y MigraDoc](https://github.com/empira/PDFsharp) | Cotizaciones en PDF | MIT |
| [.NET MAUI](https://github.com/dotnet/maui) y ASP.NET Core Components | Aplicación y BlazorWebView | MIT |
| [Microsoft.Data.Sqlite](https://github.com/dotnet/efcore) | Base de datos local | MIT |
| [SQLitePCLRaw](https://github.com/ericsink/SQLitePCL.raw) / [SQLite](https://sqlite.org) | Motor SQLite | Apache 2.0 / dominio público |
| [VortexApi.Client](https://github.com/ArcGabito/vortex-api) | SDK del hub | AGPL-3.0 |
| [xUnit](https://github.com/xunit/xunit) | Pruebas | Apache 2.0 |

Los íconos de la interfaz son trazos SVG propios del proyecto.
